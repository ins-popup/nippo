# T8 日報・売上・在庫管理（GitHub Pages版）

京都高島屋S.C. T8 POPUP の、売上・在庫の入力と日報を行うWebサイトです。
ログインなしで開けるURLになり、スタッフ用の「合言葉」を入れて使います。データはGoogleスプレッドシートに保存されます。

## 仕組み

- サイト本体：GitHub Pages（このフォルダの index.html など）
- 保存先：Googleスプレッドシート＋Google Apps Script（apps-script/Code.gs）
- 写真：Googleドライブの専用フォルダ（自動作成）
- 売上や商品のデータは、このリポジトリには入りません

## セットアップ（初回のみ・約15分）

### A. Google側（アカリさんのGoogleアカウントで行います）

1. Googleスプレッドシートを新規作成します（名前の例：T8日報データ）。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードをすべて消して、apps-script/Code.gs の中身を貼り付け、保存します。
4. 左の歯車「プロジェクトの設定」を開き、「スクリプト プロパティ」に2つ追加します。
   - `PASSCODE`：スタッフ（販売代行の方を含む）に伝える合言葉
   - `ADMIN_CODE`：管理者（アカリさん）だけが使うコード（合言葉とは別のもの）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
6. 「デプロイ」を押し、表示される権限の確認を許可します（スプレッドシートとドライブの利用）。
7. 表示された「ウェブアプリのURL」（末尾が /exec）をコピーします。

※ Code.gs を後から直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」で更新します。

### B. GitHub側

1. GitHubで新しいリポジトリを作ります（名前の例：t8-nippo）。無料プランでPagesを使うには Public にします。
2. このフォルダの中身（index.html、config.js、data.js、.nojekyll、apps-script フォルダ、README.md）をアップロードします。
   「Add file」→「Upload files」で、フォルダの中身をドラッグします。
3. リポジトリ上で config.js を開き、鉛筆アイコンで編集して、A-7 のURLに書き換えて保存します。
4. 「Settings」→「Pages」で、Branch を main、フォルダを /(root) にして Save します。
5. 数分後に、https://（GitHubのユーザー名）.github.io/（リポジトリ名）/ で開けます。

### C. 初回の準備

1. サイトを開き、PASSCODE の合言葉を入力します。
2. 「商品マスタが未登録です」の画面で、ADMIN_CODE と、別途お渡しした「T8_商品マスタ_登録用.json」を選んで「登録する」を押します。
   （商品の価格・投入数が入っているため、リポジトリには置かず、この画面から登録します）
3. スタッフにURLと合言葉を伝えます。各自、画面上の「入力者」に名前を入れてから使います。

## 注意

- 保護は合言葉のみです（メールで承認する方式ではありません）。合言葉が広まった場合は、スクリプトプロパティの PASSCODE を変更すると、全員が入り直す形になります。
- サイトのURLと config.js のURLは公開されますが、合言葉がなければデータは取得できません。
- 写真は「リンクを知っている人が見られる」設定でドライブに保存されます。URLを知らない人は見られません。
- 表示は20秒ごとに自動で更新されます。入力した直後は、自分の画面にはすぐ反映されます。
- データはスプレッドシートの「docs」シートに保存されます。直接編集しないでください。バックアップには、サイトの「売上」画面のCSV保存も使えます。
- 実行はセットアップしたGoogleアカウントの権限で行われます。Googleの1日あたりの利用上限はありますが、この規模の入力では問題ない想定です。
